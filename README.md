# NEXT STAGE 2026.10.07 공연 운영 통합 시스템

전남앵커 공연음악 인력양성 프로젝트 "NEXT STAGE" 공연(2026년 10월 7일 수요일 19시 30분, 빛고을시민문화관 공연장)의 운영 자료입니다. 최종 반영 기준일은 2026년 10월 6일입니다. 모든 페이지가 하나의 큐 상태(현재 큐, 진행 시간)를 공유합니다.

## 페이지

| 파일 | 내용 |
|---|---|
| `index.html` | 홈, 런다운, 영역별 자료 목록 |
| `1-ops.html` | 큐 진행 (처음 열면 런다운과 무대 배치도) |
| `2-mc-script.html` | 사회 8회 위치와 대본 |
| `3-mic-plan.html` | 보컬 · 코러스 마이크 플랜 |
| `4-video-light.html` | 영상 · 조명 큐 계획 |
| `5-backstage.html` | 백스테이지 입퇴장 동선 |
| `6-site-prep.html` | 당일 공정표, 좌석, 스탭, 식사 |
| `7-checklist.html` | 실행 점검 목록과 큐시트 변경 이력 |
| `8-cast-sheet.html` | 순서별 출연자 및 무대 위치 (인쇄 가능) |
| `9-venue-notes.html` | 극장 기술 협의 사항 |
| `10-stage-plot.html` | 무대 배치도 (평면, 단면, 덧마루 산출) |
| `11-seat-zones.html` | 좌석 구역 배치도 (편집, 저장, CSV/JSON/SVG, 인쇄) |
| `12-drawing-set.html` | 무대 도면 세트 A3 7장과 수치 계산 |
| `13-conti-movement.html` | 출연자 입퇴장 타임라인과 큐별 동선 콘티 |
| `14-conti-sound-light.html` | 마이크 매트릭스, 조명 색 콘티, 호출 체인 |
| `assets/` | 스타일, 데이터(`data.js`), 도면 · 콘티 생성 스크립트 |
| `images/` | 사진, 런다운(`rundown.svg`), 무대 평면도(`stage-plan.svg`), 도면 SVG(`dwg/`) |
| `files/` | 원본 좌석 엑셀, 수치 계산서 엑셀 |

데이터는 `assets/data.js`에 있습니다. 곡, 출연자, 시간표를 바꾸려면 이 파일을 고치면 모든 페이지에 반영됩니다.

## 열어 보는 방법
- 내려받은 폴더에서 `index.html`을 더블클릭하면 브라우저에서 열립니다.
- GitHub Pages로 공개하면 주소 하나로 볼 수 있습니다.

## 알아둘 점
- 체크리스트, 마이크 점검, 좌석 지정은 각자 브라우저에만 저장됩니다.
- 파일명은 모두 영문입니다. 한글 파일명은 맥에서 올릴 때 형식이 달라 링크가 깨질 수 있습니다.
- 공개 저장소는 인터넷의 누구나 출연자 이름과 운영 일정을 볼 수 있습니다.
